Zero Maven Repository

基于 GitHub Pages 的 Maven 制品仓库，groupId 为 org.zero。 仅发布 release 版本，发布后不可变。

使用方式

在项目的 pom.xml 中声明本仓库（仅作为附加 repository，不要配置为 mirror）：

<repositories>
    <repository>
        <id>zero-github</id>
        <url>https://cnzeropro.github.io/maven-repository/</url>
    </repository>
</repositories>

推荐通过 common-bom 统一管理版本（按实际发布版本替换 ${zero.version}）：

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.zero</groupId>
            <artifactId>common-bom</artifactId>
            <version>${zero.version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

版本查询

可用构件及其版本以各构件目录下的 maven-metadata.xml 为准， 可直接浏览 org/zero/ 目录查看。

GitHub Pages 走 CDN，新发布版本的元数据可能有数分钟缓存延迟； 本地构建长时间未更新的可加 -U 强制刷新。
